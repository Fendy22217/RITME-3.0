Pasang RITME di HP Android

Untuk memasang RITME seperti aplikasi biasa:

  1. Pastikan aplikasi dibuka melalui alamat website HTTPS (contohnya GitHub Pages), bukan dari file ZIP atau file HTML.
  2. Di Google Chrome, tekan menu ⋮ di pojok kanan atas.
  3. Pilih Install app atau Tambahkan ke layar utama.
  4. Konfirmasi pemasangan. Ikon RITME akan muncul di layar HP.

Jika tombol pemasangan otomatis tersedia, RITME akan menampilkan permintaan instalasi langsung.
