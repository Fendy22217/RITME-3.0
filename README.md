## Instalasi Android
PENTING: Tombol instalasi hanya dapat menjalankan prompt otomatis setelah aplikasi dipublikasikan melalui HTTPS dan dibuka dari browser yang mendukung PWA. Jika prompt tidak muncul, tombol menampilkan panduan: Chrome ⋮ → Install app / Tambahkan ke layar utama.
1. Ekstrak ZIP.
2. Upload SEMUA isi folder ke root repository GitHub.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Buka URL GitHub Pages di Chrome Android. Tekan tombol "Instal di HP" pada aplikasi atau menu Chrome ⋮ → Install app / Tambahkan ke layar utama.
Jangan membuka index.html langsung dari file manager; PWA memerlukan HTTPS. Data disimpan lokal di perangkat, tidak otomatis tersinkron. Backup JSON untuk memindahkan data.
